# GitHub publication

The project is published as a self-contained research subproject at:

```text
ENRICOBIGNOZZI/MACHINE-LEARNING/projects/certified-stock-ranking
```

Development branch:

```text
agent/certified-stock-ranking-jkp
```

The initial publication is reviewed through draft pull request `#1`. The parent
repository contains a path-scoped GitHub Actions workflow at
`.github/workflows/certified-stock-ranking.yml`; licensed data and credentials
remain outside Git.

A future migration to a standalone repository named
`ENRICOBIGNOZZI/certified-stock-ranking` can preserve the complete local history
using the distributed Git bundle, but it is not required to reproduce or review
the current project.
